## 1. 现状与约束

v0.2 已经具备：三视图、无限滑动窗口、一键清屏、40 步撤销、自动存档、分享链接、`Clock.length/seek`。
第二阶段可以直接复用的东西：

- `History` 快照栈：新增的曲长/循环字段天然可撤销。
- `song.ts` 编解码 / 存档：扩成 v2 即可。
- `songGroup` 滑动窗口与逐帧网格：是「可伸缩棋盘」的基础。
- 玻璃抽屉语言：配置面板与示例面板都复用同一套材质/间距，不新增第四层浮层。

需要解决的五个结构问题：

| # | 现状 | 影响 |
| --- | --- | --- |
| 1 | 曲长是隐式的：有限模式恒 16 步，无限模式按内容自动扩 | 无法显式调「时长」 |
| 2 | 舞台宽度固定 16 列，`X0 = -COLS / 2` 写死在 `scene.ts` 顶部 | 棋盘边缘无法伸缩 |
| 3 | 空网格按下 = 放一块并立刻进入拖动 | 没有笔触概念，不能连续绘制 |
| 4 | 循环永远开启，BPM 只在 transport，没有面板 | 配置散落 |
| 5 | 示例只有内置 `DEMO` 一首 | 无法快速切换风格 |

## 2. 设计原则

1. **非破坏性优先**：拖棋盘边缘只改视口；改曲长、载入示例这类会动数据的操作必须进撤销栈 + toast。
2. **一笔 = 一次撤销**：连续绘制整条笔触只占一个历史条目。
3. **面板复用玻璃语言**：右侧抽屉，与 transport / 顶栏同级；不把半透明叠在半透明上。
4. **旧数据必须能打开**：v0.2 的本地存档、分享链接、`SongState` 快照全部向后兼容。
5. **键盘可达**：抽屉 `role="dialog"` + 焦点管理，`Esc` 关闭；滑杆支持方向键。
6. **reduced-motion 全路径**：面板开合、示例载入、棋盘伸缩都有降级。

## 3. F4 连续拖拽绘制（M1，先做）

### 3.1 状态机

```
idle → hover
  ├─ pointerdown 在已有方块上 → move（v0.2 的拖动，保持不变）
  ├─ pointerdown 在空格上     → paint（新）
  └─ pointerdown 在舞台外空白 → orbit（相机，保持不变）
paint → pointermove：落格、补格、发声
paint → pointerup/pointercancel：提交一笔历史
```

### 3.2 落格算法（已确认 3A：跟随指针 + 行滞回）

- 每次 `pointermove` 用 `pointerToCell`（地板 y=0 平面）得到 `(step,row)`。
- 默认 **跟随指针**：行随指针走，但加 **半格行滞回**（未越过相邻行中线不换行），避免手抖串音色。
- `Shift` **锁定起始行**：只补横向的格子，适合画一条固定音色的旋律线。
- 快速移动会跳格：对上一格到当前格做 **网格插值**（Bresenham），把经过的格子全部补上，保证不断线。
- 已占用的格子跳过，不覆盖、不重复发声。
- 单次移动最多补 32 格，防止异常事件刷爆。

### 3.3 反馈

- 新方块不做 v0.2 的"从高处落下"，改用 0.85 → 1 的小 pop（spring response 0.2 / damping 0.9），像笔尖点上去。
- 每补一格发一次该行音色，增益约 0.3；同一批超过 8 格时只发前 8 格，交给压缩器兜底。
- 光标：空格上为 crosshair；已有方块上为 grab；拖动边缘为 ew-resize。
- 提示文案改为「网格上拖动画音符 · 背景拖拽转视角 · 右键删除」。

### 3.4 撤销与自动滚动

- `pointerdown` 时保存 `SongState` 快照；`pointerup` 时若 `added > 0`，一次性 `history.push(snapshot)`。
- 画到窗口右缘 1 列内并持续 120ms：窗口自动前移 1 列（无限模式/长曲），笔触继续，松开后窗口停在当前位置。
- 右键拖拽 = 连续擦除（P1，可放进 M1 末尾，同样一笔一次撤销）。

### 3.5 与现有手势的关系

- 舞台内拖动 = 画音符；舞台外背景拖动 = orbit。棋盘几乎占满画面时，背景只剩边距——所以 **触屏追加双指 orbit**（P1，M1 内做基础版）。
- 已有方块上按下仍然是拖动/交换，不进入 paint。
- 滚轮改音高、右键单击删除、Delete 删除全部保留。

### 3.6 技术改动

- `main.ts`：新增 `PaintStroke` 状态与 `pointerdown/move/up` 分支；`record()` 从"每次放置"改为"一笔一次"。
- `scene.ts`：`addBlock` 增加 `pop` 选项（不走 2.6 高空延迟）；空闲时不再给新块 `beginDrag`。
- `audio.ts`：无需改，沿用 `play()`；笔触音效可复用 `sfx_place` 轻量版（可选）。

### 3.7 验收

- 按住横拖 4 格得到 4 块，`⌘Z` 一次全部撤掉；再 `⇧⌘Z` 全部回来。
- 快速拖过 10 格无断线；斜向拖动有连续轨迹。
- `Shift` 锁定行；行滞回在 1px 抖动下不串行。
- 拖已有方块仍然是移动；舞台外拖动仍然 orbit。
- 俯视图、无限窗口、移动端触屏都能连续画。

└─────────────────────────────┘

### 4.2 曲长：从隐式变成显式（SongState v2）

```ts
interface SongState {
  notes: Note[];
  bpm: number;
  infinite: boolean;
  bars: number;   // 1..32，每小节 16 步
  loop: boolean;  // 播完循环 / 停在末尾
}
```

- 有限模式：`Clock.length = bars * 16`，循环由 `loop` 控制。
- 无限模式：`length = max(bars * 16, 内容整小节)`，写到后面自动增长（上限同 bars 上限）。
- 时长读数：`bars * 16 * (60 / bpm / 4)` 秒，格式 `0:08.9`。
- **缩短曲长不能切掉音符**：下限 = 最后一个音符所在小节；低于它时输入被夹住并 toast「第 5 小节还有音符」。
- `Clock` 增加 `loop`：关闭时播到末尾停止，播放键变成"从头播"；按空格从末尾重播会先 rewind。
- 改变曲长/循环/BPM 都进撤销栈（滑杆拖动按一次手势合并）。

### 4.3 声音与偏好

- `AudioEngine` 增加 `setMasterGain(v)`、`setReverbSend(v)`（`setTargetAtTime` 平滑，避免爆音）。
- 偏好独立存档：`note-block:prefs:v1`，不进分享链接、不占撤销栈。
- 配置面板里的 BPM/曲长/循环属于「曲子」，跟随存档与分享；音量/混响属于「本机偏好」。

### 4.4 布局与可访问性

- 抽屉从右侧滑入（transform 260ms `cubic-bezier(.23,1,.32,1)`），`Esc`/点外部关闭；桌面不加全屏遮罩，窄屏加 0.18 遮罩。
- 打开时焦点进入面板，关闭归还触发按钮；滑杆原生方向键语义；数值用 mono 字体。
- 所有控件都有 label；开关是 `role="switch"`；状态用 `aria-*` 同步。

### 4.5 验收

- 曲长 1–32 小节可调，读数正确；缩短到音符之前被夹住并提示。
- 循环关闭后播放到末尾停止，再按播放从头开始。
- BPM、音量、混响刷新后保持；分享链接在其他浏览器打开后曲长/循环/BPM 一致。
- 面板键盘可完整操作，`Esc` 关闭；reduced-motion 下直接出现。

## 6. F2 棋盘双边拖拽（M4，最大重构）

### 6.1 语义（已确认 1A：视口宽度）

- **采用 A：拖边缘 = 调整视口宽度**。8–32 列，按 4 列（一小节）吸附；只改「看见多少」，不改曲子数据；曲长在配置面板里调。非破坏性，与 v0.2 的滑动窗口模型一致。
- B（拖边缘改曲长）与 C（`⌥` 混合）未采用，记录备查：B 的左边缘会整体平移音符、属于破坏性编辑，且与配置面板里的「曲长」语义重叠；C 的可发现性差。

### 6.2 几何/坐标重构（关键）

v0.2 的 `X0 = -COLS / 2` 把窗口宽度写死进了方块局部坐标。v0.3 改成「内容坐标只依赖 step，舞台偏移单独算」：

```
v0.2:  block local x = X0 + step + 0.5       songGroup.x = -viewStart
v0.3:  block local x = step + 0.5            songGroup.x = -W/2 - viewStart

世界坐标     x = step + 0.5 - W/2 - viewStart
播放头       x = pos - W/2 - viewStart
网格边界 s   x = s - viewStart - W/2
指针反算     localX = worldX + W/2 + viewStart
            step = round(localX - 0.5)
舞台内坐标   stageX = localX - viewStart ∈ [-0.5, W + 0.5]
```

默认 `W = 16` 时与 v0.2 逐像素等价。需要同步替换的位置：`cellX/stepFromX`、指针/拖拽/场外判定、幽灵与选中框、播放头、动态网格、地板宽度、舞台 slab、水平线、相机 fit（`STAGE_HALF_W = W/2 + 0.9`）、阴影相机范围。

### 6.3 手柄与手势

- 左右各一枚圆角竖条手柄，位于石板边缘中点附近；平时 0.0 透明度，指针进入边缘 18px 或手柄时淡入（0.9），拖拽时保持显示并放大 1.06。
- 指针命中优先于方块拾取；按下进入 `resize` 状态，`setPointerCapture`，`Esc` 取消回原宽度。
- 拖动换算：以棋盘中心为锚点对称伸缩。右边缘世界 x = `W/2`，拖拽位移 dx 时 `W' = W + 2dx`；左边缘同理 `W' = W - 2dx`。按 4 列吸附；到边界时退化为单侧伸缩，`viewStart` 夹到 0 / 最大滚动位。
- 拖拽中在光标旁显示玻璃小胶囊：`6 小节 · 24 列`；每跨过一小节发一次极轻的 tick。
- 松开：一次弹簧落位（response 0.35 / damping 0.9），保存偏好，触发相机 fit。

### 6.4 舞台重建与相机

- `W` 变化只在跨过 4 列吸附时触发重建：slab/base + 8 条地板 + veil + 水平网格线；贴图复用（只改 repeat），几何 dispose。
- 重建耗时按 <2ms 预算；一次拖拽最多跨 6 次小节，不会成为瓶颈。
- 阴影相机范围随 `W` 扩大（`max(14, W/2 + 6)`）；相机 fit 用新半宽重新求距，用现有 exp 阻尼过渡。
- 窗口列数也写进配置面板，和边缘拖拽共用 `setWindowCols()`。

### 6.5 验收

- 左右边缘都能拖，8–32 列，4 列吸附；拖动时棋盘对称伸缩、方块/网格/播放头始终对齐。
- 拖动不改变任何音符、曲长、分享内容；刷新后窗口宽度保持。
- 三视图、竖屏、无限跟随、清屏、撤销全不受影响；默认 W=16 与 v0.2 视觉一致。
- 边缘手柄在触屏上 44px 命中区；拖拽时音符不被误拾取。

| --- | --- |
| 动态窗口重构影响 v0.2 全部几何/指针逻辑 | 先做坐标解耦（默认 W=16 逐像素等价），再加手柄；每一步跑现有 23 项浏览器回归 + 新增边缘拖拽用例 |
| 连续绘制与 orbit / 拖动方块抢手势 | 只在「舞台内空格」上绘制，背景仍 orbit；已有方块仍拖动；触屏补双指 orbit |
| 缩短曲长切掉音符 | 下限夹到最后一个音符所在小节，输入被夹住并提示；不静默删数据 |
| 示例载入覆盖作品 | 撤销 toast + backup 槽 + 配置面板恢复入口；自动存档仍在 |
| 旧分享链接/存档打不开 | 解码器保留 v1 分支；用固定 v1 样本做回归 |
| 32 列时绘制/阴影开销上升 | 可见块剔除沿用 v0.2；阴影相机随宽度扩；真到瓶颈再按行做 InstancedMesh（本轮不做） |
| 面板/抽屉叠玻璃层 | 复用同一抽屉组件，桌面不加遮罩，窄屏遮罩只压暗不加 blur |
