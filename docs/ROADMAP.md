## 2. 设计原则（新功能必须遵守）

1. **相机只滑行、不回弹**；任何过渡都能被下一个操作中途接住。
2. **无限不是"更大的画布"，是"更长的曲子 + 会滑动的窗口"**：舞台尺寸、构图、光照都不变。
3. **破坏性操作必须有回家的路**：一键清屏 = 一键 + 5 秒撤销。
4. **"波"是唯一的过场语言**：装配、换材质、清屏、撤销都用波，速度统一在 12–14ms/列。
5. **声音是因果不是装饰**：扫频跟着波前走，落地声跟着最后一块方块消失。
6. **拒绝新依赖、新素材、新配色**；行 = 音色的概念不动。

## 3. 功能 A：快速三视图

### 3.1 交互

- 顶栏右侧新增三枚分段按钮（玻璃胶囊，和现有圆形按钮同语言）：**透视 / 俯视 / 正视**；当前视图用墨色填充高亮（不用红，红仍是播放/选中/错误专用）。
- 快捷键 `1` `2` `3`；`V` 循环；鼠标拖拽空白/滚轮即进入"自由"状态，按钮高亮自动熄灭——预设与自由是同一个状态机的两种状态。
- 切换时相机约 480–600ms 滑行；`prefers-reduced-motion` 下 120ms。
- 切换音效：极轻的 `sfx_click`（现有素材），按视图序号吸附到当前调内音高，增益约 0.2。

```
┌──────────────────────────────────────────────────┐
│ ▪ NOTE BLOCK 音符方块          [透][俯][正]  ○ ◉ │
└──────────────────────────────────────────────────┘
```

### 3.2 三个机位（初值，实现时按投影微调）

| 视图 | az | el | fov | lookAt.y | 视差 | 用途 |
| --- | --- | --- | --- | --- | --- | --- |
| 透视（默认） | 0.50 | 0.70（40°） | 30 | -1.25 | ±0.055 rad | 作曲主视角，沿用今天 |
| 俯视 | 0（竖屏 π/2） | 1.45（83°） | 30 | -0.40 | ±0.008 rad | 读谱：列=时间、行=音色、顶面=音高 |
| 正视 | 0 | 0.34（19°） | 30 | -0.75 | ±0.02 rad | 看体块与材质侧面，低机位产品照 |

- 距离不写死：由「舞台 + 方块高度」包围盒的四角投影，按当前 `aspect` 求最小 `dist`（margin 1.08）；**resize / 横竖屏自动重算**。
- 竖屏：俯视 `az = π/2`，让 16 列沿屏幕长边走，棋盘不缩成一条线；透视沿用现有 portrait 构图（dist 46）；正视保持 `az=0`。
- `zoom()` 的 clamp 从固定 `19–36` 改为 `fitDist × [0.75, 1.45]`，否则竖屏/远机位滚轮会失效。

### 3.3 过渡与打断

- 每个轴各自 `damp()`：az/el/lookAt λ≈5.2，dist λ≈4.6，fov λ≈5（约 500ms 到 95%）。exp 阻尼天然无过冲、天然可打断（读当前值继续）。
- 俯视/正视关闭"空闲呼吸"的 `sin(t·0.16)·0.006` 方位漂移（`scene.ts:738`）——静图要像正投影，任何微动都会让网格发糊。
- 手动 orbit/zoom 时写 `viewId = 'free'` 并清预设高亮；此时 resize 不再强拉机位。

### 3.4 俯视图可读性（"方便查看"具体做什么）

- 网格与屏幕轴对齐：主干线每 4 列、淡线每列；播放头是一条清晰的横向扫描带。
- 俯视下悬停格子不显示幽灵方块（看不到侧面），改为**描边 + 顶面高亮**。
- 保留方块高度感（83° 透视仍有轻微近大远小），但把视差压到近乎 0。
- 行图例高亮鼠标所在行——俯视图里唯一真正需要的额外信息。
- 可选（P2）：悬停显示音高读数 chip（如 `F#4 · Harp`）。

### 3.5 技术改动

- 新增 `src/views.ts`：`ViewId`、`VIEWS` 参数表、`fitDistance(corners, aspect, fov)`。
- `scene.ts`：`cam` 增加 `fov/lookY/tfov/tlookY`；新增 `setView(id)`、`cycleView()`、`onViewChange` 回调；`resize()` 仅在预设态下重新 fit。
- `hud.ts` / `index.html` / `style.css`：分段控件、`aria-pressed`、响应式。
- `main.ts`：接线 + `1/2/3/V` 快捷键 + 切视图音效。

### 3.6 验收

- 1440×900、1024×768、390×844 下三个按钮都能切，俯视能看到完整 16×8。
- 切换全程无画面跳变/穿模；中途反向点击能立刻接住。
- 俯视图里用鼠标放置/拖动，落格准确（误差 < 0.5 格）。
- resize 后预设机位保持构图；竖屏俯视不缩成一条线。
- 无 console error；reduced-motion 下直接切。

## 4. 功能 B：无限模式

### 4.1 定义（推荐口径）

- **时间轴无上限**：曲子可以一直往后写，不再只有 16 步；**行仍然 8 行**（行=音色是这个项目的概念核心，不做 y 轴扩展）。
- **窗口固定 16 列**：舞台尺寸、构图、光照完全不变；内容在舞台下"滑动"。
- **播放语义**：默认循环整首；曲长按内容自动取整到小节（16/32/48… 步）；播放头带着窗口走，窗口左缘 ≈ 播放头 − 70% 窗宽。
- **上限**：工程软上限 1024 步（64 小节），常量可调，触顶 toast 一次。交互上的"无限"，工程上的安全绳。

```
曲内坐标   0    4    8    12   16   20   24   28   32
窗口(16)   [================================]
viewStart=8      [================================]
viewStart=16               [================================]
舞台始终是 16 列的那块石板，内容在它下面滑
```

### 4.2 交互

| 操作 | 结果 |
| --- | --- |
| 切到无限（`∞` 按钮 / `I`） | 舞台右侧"让出"4 列（一小节）动画；16 步循环保留、锁定不可再缩 |
| 放到最右一列 | 自动再让出 4 列（像翻页），窗口平滑跟进 |
| 播放 | 窗口跟随播放头（70% 领前），能看到即将到来的音符 |
| Shift+滚轮 / 横向滚动 | 手动平移时间轴；跟随播放时作为跟随偏移 |
| 拖动进度条 / 点击步进点 | 跳转（seek），窗口立即居中所跳位置 |
| `Home` / ⏮ | 回到第 1 小节 |
| 切回有限 | 窗口回到 0–15；16 步外的方块**保留但不显示**，播放不经过它们 |

HUD 增加：`M03 / 12` 小节计数（mono 字体）；无限模式出现全曲进度条（140px 玻璃细条，可拖）。窄屏隐藏进度条，保留小节计数。

### 4.3 滚动架构（本方案最关键的一处）

**舞台不动，内容动。** 用一个 `songGroup` 包住所有随曲子走的东西（方块、顶面色片、接触阴影、幽灵、选中框、播放头），只动它的 `position.x`：

```
X0 = -W/2（W = 16）
每块局部坐标     x_local = X0 + step + 0.5        ← 今天的 cellX 不改
songGroup.x      = -viewStart
播放头 local.x   = X0 + pos
世界坐标         x = X0 + (step + 0.5) - viewStart
指针 → 格子      localX = worldX + viewStart；step = round(localX - X0 - 0.5)
```

好处：`Spring`、拖拽、吸附全部继续用今天的局部坐标；滚动只是父节点平移，不会打断任何方块动画。

**地板网格必须一起滚**，否则格线与音符错位。网格用"传送带"：内容以 4 列为周期，只画 `[0, W+8]` 并让

```
gridGroup.x = X0 - (viewStart % 4)
```

因为粗线在局部 4 的倍数上，滚动任意小数时主线始终落在绝对小节线上；跨过 4 的瞬间图案无缝回卷。地板贴图本身逐列重复、没有方向性，不需要滚。

`viewStart` 用 `damp(λ=7)` 追目标；**拖动方块时暂停跟随**（避免拖一半舞台自己跑），落手后需要再滑。窗口边缘留 1 列缓冲后剔除（`mesh.visible = false`），渲染不花钱。

### 4.4 Clock 改造

- `Clock` 增加 `length`（默认 16）与 `seek(step)` / `rewind()` / `setLength(n)`；三处写死的 `% 16` 换成 `% this.length`，`nextStep` 同理。
- 调度、120ms lookahead、视觉队列（`drainVisual`）机制**不动**——音画同帧是这项目的地基。
- 主循环按内容算长度：`length = max(16, ceil((maxStep + 1) / 16) * 16)`；加/删方块后 `setLength()`。
- 曲长变化时若 `position > length`，下一拍自然回卷；`setLength` 里做一次 re-anchor，逻辑照抄 `setBpm`。
- 循环回卷时 `viewStart` 直接归 0（不做倒带长滑，避免观众以为卡了）。

### 4.5 性能

- 可见窗口最多 16×8 = 128 块，隐藏的 mesh 不产生 draw call；`update()` 只算窗口内的方块。
- `caps/blobs` 两个 InstancedMesh 只填可见块，capacity 256 → 384。
- `hit(step)` 现在是全表扫描（`scene.ts:679-685`），改为 `Map<step, BlockView[]>` 索引，无限模式必备。
- 全曲方块仍线性占用内存（每块一个几何 + 材质）；1024 步上限下最坏约 8192 块，远超实际使用。真到瓶颈再按行做 InstancedMesh（本轮不做，避免过度设计）。

### 4.6 边界情况

- 播放中切模式：不打断音频，窗口平滑重新定位。
- 拖拽中切模式 / 清屏：先 `endDrag`（或取消）再执行。
- 曲长缩短（删块/清屏）：播放头夹到新长度内。
- 空曲无限模式：长度 16，窗口停在 0，不空转。
- 窗口滚动时悬停幽灵/选中框跟随（都在 `songGroup` 里，天然正确）。

### 4.7 验收

- 无限模式连写 8 小节（128 步）不出现硬边界；播放头始终在窗口内，窗口滑动无跳帧。
- 16 步模式行为与今天**逐帧一致**（回归：demo 曲、拖拽、滚轮、BPM、静音行、播放头）。
- 300 个方块时桌面 ≥55fps；窗口外方块不渲染（draw call 不随曲长增长）。
- 切回有限模式数据不丢；切回无限恢复。
- seek / Home 后音画仍然同帧（<10ms 目标不变）。

## 5. 功能 C：一键清屏（动画 + 音效）

### 5.1 交互与安全网

- 顶栏新增扫帚/垃圾桶图标按钮（hover 红提示破坏性），`aria-label="清空舞台"`；空舞台时置灰不可点。
- **一键执行，不弹二次确认**（要求"一键"）；代价是必须有撤销：
  - 清屏后底部出现玻璃 toast：`已清空 58 个方块 · 撤销`，5 秒后淡出；
  - `⌘Z / Ctrl+Z` 同样可撤销（先只针对最近一次清屏，完整 undo 栈放 P1）；
  - 可选快捷键 `⌘⇧⌫`。
- 清屏时：`endDrag`、隐藏幽灵/选中框；播放不中断（继续走空小节）；窗口位置不变。

### 5.2 分镜（毫秒级）

| t | 发生了什么 |
| --- | --- |
| 0 | 点击；按钮压下 0.95；`audio.wipe()` 起音；波前出现在舞台左缘 |
| 0–60ms | 全曲方块先"吸一口气"：scale 1 → 0.92（spring response 0.12，不回弹） |
| 16ms/列 | 波前向右推；每列方块被扫到的瞬间 scale→0.6 并爆 6 粒体素（继承朝上+朝右速度），接触阴影同步消失 |
| 0–420ms | 波前横穿 16 列：核心 0.07u 宽红 `#D4552C` 透明度 .65，外圈 0.9u 宽暖橙 `.16`，均 `MeshBasicMaterial depthWrite:false`，贴地 y=0.02 |
| 120ms | 相机做一次 −0.35 距离的"吸一口气"，弹簧 0.5s 回位（幅度 <1.5%，只可感不可见） |
| 300ms | `audio.thump()` 低频落地；最后一列尘土升起 |
| 420–600ms | 尘埃落定（Dust 重力 9.5 已有）；toast 出现 |

- 尘埃池容量 140 → 384，单块 6 粒；8 种材质颜色分别继承（`Dust.spawn` 已支持颜色）。
- `prefers-reduced-motion`：跳过波前/尘埃/相机呼吸，方块 140ms 淡出，音效保留但更轻。

### 5.3 声音（全合成，不加资产）

- **wipe**：1s 白噪 buffer → BandPass（Q≈1.1）频率 600→5200Hz 指数扫 0.36s；gain 35ms 起音到 0.42 再衰减；`StereoPanner` 从 −0.7 扫到 +0.7，跟着波前从左到右走；接现有 dry + 混响 send。
- **thump**：sine 140→44Hz / 0.24s，gain 0.5 快衰，低通 200Hz；落在方块清空完成的时刻。
- **撤销**：反向扫频 noise 3500→700Hz / 0.30s + 方块落位音，听觉上"倒带重建"。
- 与视觉同帧：点击处理里先 `audio.wipe()` 再 `studio.clearAnimated()`，波前位置由同一个时钟驱动，偏差目标 <30ms。
- 静音/未解锁：`AudioEngine` 已有 `muted`/`ready` 守卫，动画照常。

### 5.4 撤销实现

- 清屏前 `snapshot()`：`{ blocks: [{step,row,midi}], viewStart, bpm, length, infinite }`；
- `restore()`：`clear()` → 按 step 顺序 `addBlock(..., animated=true, delay=…)` 反波重建（delay 上限 0.5s，避免长曲迟滞）；窗口回到快照位置；
- 撤销音效 + toast 消失；连续点清屏只保留最近一份快照（幂等）。

### 5.5 验收

- 清屏从点击到最后一个方块消失 ≤600ms；toast 5s 内可撤销，`⌘Z` 可撤销，撤销后位置/音高/模式 100% 还原。
- 清屏与播放、拖拽、无限窗口滚动同时发生时无异常；连点不重复触发。
- 音效与波前同步（耳测 + AnalyserNode 峰值对比 <30ms）。
- reduced-motion / 静音 / 空舞台三种路径都正常。

## 9. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 滑动窗口与"产品摄影"构图冲突 | 舞台固定、只滑内容；窗口边缘 1 列缓冲后剔除；若仍有"凭空出现"感，再加边缘柔化（shader 或遮罩）作为后备 |
| 相机 fit 在极端比例/竖屏下不准 | 用包围盒四角投影求 extent，按每视图分别写 portrait 规则；zoom 上下限基于 fitDist 动态计算 |
| Clock 改造引入音画不同步 | 只改长度与取模，不动 lookahead/视觉队列；补 3 个回归用例（16 步循环、BPM 切换、seek 后调度） |
| 一键清屏误触 | 一键 + 5s toast 撤销 + ⌘Z；不做二次确认（违背"一键"）；空舞台按钮置灰 |
| 无限模式内存 / 绘制上涨 | 窗口剔除（隐藏 mesh 不产生 draw call）、只填可见 caps/blobs、step 索引、1024 步上限 |
| 三视图与 orbit/zoom 状态冲突 | 手动手势即进"自由"，清按钮高亮；resize 仅预设态下重新 fit |
| 移动端按钮/手势拥挤 | 窄屏视图按钮只留图标；进度条隐藏；俯视双指横滑时间轴（P2） |

### 12.2 与初版方案的偏差（都是实现时判断）

- 竖屏下**三个**视图都转到 `az = π/2`（不止俯视）：否则 3/4 透视在 390×844 上会缩成一条，实测 dist 从 93.6 降到 55.7。
- 清屏波前 0.34s、16ms/列（原方案写 14ms/列）：给体素尘和 thump 留出时间，实测更从容。
- 网格没有采用"传送带 group 位移"，改为**每帧重画可见的绝对步边界**：顶点只有几十个，更简单且不会出现周期回卷误差。
- 清屏/撤销/分享/存档按 scope B 一起交付；`∞` 上限 1024 步。

### 12.3 验收结果

- `npx tsc --noEmit`：0 error；`npm run build`：通过。
- 自动化浏览器回归（`.scratch/final-test.cjs`，冻结 rAF + CDP 截图）：**23/23 通过，0 console error / 0 pageerror**。
  覆盖：三视图机位与 aria、键盘快捷键、透视/俯视放置、拖动、无限窗口放置与平移、清屏/撤销/重做、
  分享 URL 往返、localStorage 恢复、reduced-motion、竖屏布局与三视图旋转、draw call 上限。
